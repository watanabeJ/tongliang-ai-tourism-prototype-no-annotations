# V6 商户端界面规划图

> 继承基线：`V6商户端界面规划图-20260827-v19.md`。
>
> 本次确认变更：工作台经营助手入口卡片改为 AI 助手自我介绍结构。左侧显示 AI 机器人头像，右侧说明内容数量、预计耗时和补充价值，底部统一使用“开始补充”按钮。

## 工作台入口结构

```text
┌──────────────────────────┐
│  [AI机器人]  我是AI经营助手，          │
│              我帮您整理了 5 项内容，   │
│              大约需要 5 分钟，请您确认后，│
│              AI会更好的向游客推荐您的店铺 │
│                          │
│        [开始补充]         │
└──────────────────────────┘
```

## 规则

- 使用熟悉的机器人图标表达 AI 助手身份。
- 文案使用“您”和“您的店铺”，保持面向商户的服务语气。
- 卡片不再单独展示剩余数量或继续进度文案。
- 按钮统一为`开始补充`，点击后仍在工作台打开底部核对列表。
