# V6 商户端界面规划图

> 继承基线：`V6商户端界面规划图-20260827-v4.md`。
>
> 本次确认变更：进一步压缩经营助手操作路径。删除独立的“经营助手准备页”和“本次完成页”，工作台直接进入经营助手对话页；AI 整理过程在对话页内以短暂过渡呈现；全部处理完成后在对话页内弹出完成弹窗。

## 一、最终主路径

```text
工作台
  ↓ 点击“开始核对”
经营助手对话页
  ↓ AI 短暂整理
逐项核实信息 / 回答游客问题
  ↓ 全部完成
完成弹窗
  ↓ 返回工作台或查看店铺信息
```

核心路径只有一次页面跳转，商户点击“开始核对”后直接看到第一条需要处理的内容。

## 三、工作台设计

工作台只回答三个问题：这是哪家店、经营助手能做什么、现在是否需要开始。

```text
龙乡小馆                         商户资料

经营助手
帮你核实店铺信息，回答游客常问的问题

平台整理了 5 项内容
大约 3 分钟完成

[→ 开始核对]

你只需要告诉我现在的情况，其他交给经营助手。
最近一次核对    今天 15:30
```

### 工作台规则

- 唯一主按钮：`开始核对`。
- 有未完成内容时显示“平台整理了 X 项内容”；无新内容时改为“目前没有需要核对的内容”。
- 不出现待确认、待回答、已完成数字，不出现状态页签。
- 不出现“知识”底部导航；商户资料仍在顶部右侧。

## 四、经营助手对话页设计

### 1. 页面首屏与 AI 整理

点击工作台按钮后进入 `assistant.html`，先显示约 0.5 秒的过渡：

```text
        ✦
正在整理需要和你核对的内容……
很快就好
```

整理结束后直接显示第一项，不再让商户点击“开始核对”。

### 2. 对话布局

```text
‹ 经营助手                         1 / 5

✦ 经营助手
我们先确认店铺信息

┌──────────────────────┐
│ 平台资料显示：        │
│ 每天 10:00—21:00      │
│                      │
│ 现在还是这样吗？       │
└──────────────────────┘

[准确]             [需要修改]

你的回答会先经过平台审核，审核期间不影响继续使用。
```

### 3. 信息核实

- `准确`直接进入下一条。
- `需要修改`在当前气泡下展开输入框，不跳页；按钮变为`保存修改`。
- 修改提交后自动进入下一条。
- 输入内容为空时提示`请填写现在的情况`。

### 4. 游客问题回答

- 进入问题阶段时，AI 先发一句过渡：`店铺信息已经确认好了，接下来回答几个游客常问的问题。`
- 当前问题只显示一个输入框和两个动作：`提交回答`、`不适用`。
- `不适用`使用确认弹窗，确认后自动进入下一条。
- 商户不能新增、删除或修改平台问题。

### 5. 退出与恢复

- 返回工作台不会丢失已提交内容。
- 下次点击`继续核对`时，从第一条未完成内容开始。
- 已提交内容不在对话页重复显示操作按钮。

## 五、完成弹窗

全部内容处理完毕后，在当前对话页底部弹出：

```text
┌────────────────────┐
│         ✓          │
│ 这次核对完成了      │
│                    │
│ 已确认 2 条店铺信息 │
│ 已回答 3 个游客问题 │
│                    │
│ 平台审核后，AI 会使用│
│ 更新后的内容回答游客 │
│                    │
│ [完成并返回工作台]  │
│    看看店铺信息     │
└────────────────────┘
```

- 主按钮关闭弹窗并返回工作台。
- 次按钮进入商户资料下的店铺信息只读页。
- 不产生“完成页”路由，不展示完成率、贡献值或状态管理。

## 六、交互与视觉验收

1. 从工作台到第一道问题只有一次页面跳转。
2. AI 整理是对话页内的短暂过渡，不单独占用页面。
3. 信息核实和问题回答在同一页面连续完成。
4. 完成结果使用弹窗，不生成独立完成页面。
5. 工作台不展示知识状态、数量统计或传统任务列表。
6. 继续沿用 V5 的无手机边框、375px 画布、浅灰绿色背景、深绿色主色和白色内容区域。
