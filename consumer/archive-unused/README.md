# 用户端归档页面

此目录仅保存当前 V6 用户端主流程不再使用的历史页面副本，不作为预览入口或功能依赖。

| 文件 | 归档原因 |
| --- | --- |
| `未使用-check-in.html` | V6 已移除心愿单打卡、到访打卡和相关生成流程。 |
| `未使用-index.html` | V6 预览入口已统一使用 `consumer/plan.html`，旧首页不再参与页面跳转。 |
| `未使用-profile.html` | 当前首页和左侧抽屉均无“我的”入口；该页只连接已下线的计划、收藏和订单页面群。 |
| `未使用-favorites.html` | 仅由已不可达的“我的”页进入，当前用户端主流程无入口。 |
| `未使用-favorite-conversation.html` | 仅由已不可达的收藏页进入；根目录副本与本归档副本内容完全一致，已只保留此归档文件。 |
| `未使用-all-plans.html` | 仅由已不可达的“我的”页进入，当前用户端主流程无入口。 |
| `未使用-history.html` | 旧“最近看过/订单”页面；此前仅被商品详情页作为无来源时的遗留返回兜底，且自身返回到已不可达的“我的”页。商品详情兜底已改为当前首页。 |
| `未使用-orders-pending.html` | 仅由已不可达的“我的”页或订单页内部状态导航进入。 |
| `未使用-orders-usable.html` | 仅由已不可达的“我的”页或订单页内部状态导航进入。 |
| `未使用-orders-review.html` | 仅由已不可达的“我的”页或订单页内部状态导航进入。 |
| `未使用-orders-all.html` | 左侧抽屉的“全部订单”入口已移除；剩余引用仅来自不可达的“我的”页和订单页内部状态导航。 |

当前保留在 `consumer/` 根目录的页面为：`plan.html`、`explore.html`、`activity-detail.html`、`product-detail.html`。商品详情页优先返回会话记录的来源页或浏览器上一页；两者都不可用时返回 `plan.html`。

归档文件保留用于追溯，不应被预览服务、有效页面或新功能直接引用。若后续恢复相关业务，应先将页面移回 `consumer/` 根目录并重新核查入口与返回路径。
