# 政府端运营总览原型（v6 · v8）

继承基线：`government-20260828-v7`。本版统一补充“全部”时间维度，并调整各时间维度统计口径，旧版本不修改。

## 时间口径

- 今日：只统计当前自然日的数据。
- 本周：只统计当前自然周的数据。
- 本月：只统计当前自然月的数据。
- 全部：统计平台自运行以来的全部数据。

运营总览保留五个入口框：用户、商户、负面、热点采用 2×2 紧凑网格，运行报告单独占一行。点击后进入原有独立子页。

## 独立页面

- `login.html`：账号密码登录。
- `index.html`：运营总览和各功能入口。
- `users.html`：用户总量、新增用户量、变化趋势。
- `merchants.html`：商户总量、新增商户量、变化趋势。
- `negative-feedback.html`：负面反馈总量、分类饼状图。
- `hot-topics.html`：热点问题总量、分类饼状图。
- `report.html`：当前时间维度的数据摘要和 AI 运行总结。

各功能页均支持今日、本周、本月、全部切换，公用 `styles.css` 和 `app.js`，可以独立修改 HTML 结构。

当前功能页允许直接打开，不再校验登录状态或自动跳转到登录页；`login.html` 仅保留为登录流程原型。
