# 铜梁旅游商户端 - 商户资料

## 页面摘要

展示商户资质审核进度、已提交证件和当前门店资料概览。商户可从门店信息区进入统一的门店资料维护页；本页不再提供“账号与安全”或“修改密码”入口。

## 页面模块

- 审核进度：展示资料提交、平台审核和审核结果三个节点。
- 审核提示：审核中不影响正常使用；当资质需修改时展示审核意见入口。
- 已提交资料：展示营业执照、经营许可证、法人身份证和联系人信息；证件资料仅支持脱敏预览。
- 门店信息：展示当前账号绑定门店的七项维护字段，并跳转至门店信息页编辑。

## 审核状态与权限

- 审核中时，商户可继续查看和编辑门店信息、回答游客问题、导入自己的知识材料和修改密码。
- 资质状态为“需修改”时，商户仍可登录；仅重新提交资质资料受限，其他已开放功能继续可用。
- 资质审核与 AI 内容合规审核独立执行，互不阻断。

## 【门店信息】字段说明

| 字段 | 本页展示 | 必填 | 维护方式 |
|---|---|---|---|
| 门店名称 | 当前名称 | 是 | 点击字段或“去维护”进入门店信息页。 |
| 详细地址 | 当前地址 | 是 | 点击字段或“去维护”进入门店信息页。 |
| 门头照 | 上传状态 | 是 | 点击字段或“去维护”进入门店信息页。 |
| 商户简介 | 当前简介摘要 | 是 | 点击字段或“去维护”进入门店信息页。 |
| 特色菜介绍 | 当前内容或“未填写” | 否 | 点击字段或“去维护”进入门店信息页。 |
| 商户电话 | 当前号码或“未填写” | 否 | 点击字段或“去维护”进入门店信息页。 |
| 美团门店链接 | 当前链接或“未填写” | 否 | 点击字段或“去维护”进入门店信息页。 |

## 门店信息交互规则

- 当前手机号仅对应一个商户账号和一个门店，本页只展示该绑定门店的信息。
- 点击任一门店字段行或“去维护”，进入 `store-info.html` 进行字段级编辑；本页只展示结果，不直接保存字段。
- 从门店信息页保存文本字段后，本页重新进入时读取本地演示数据并展示最新值。
- 必填字段缺失不得在门店信息页保存；非必填字段为空时显示“未填写”，不影响其他字段保存。
- 美团门店链接允许为空；填写时仅允许标准 `http://` 或 `https://` URL，格式或协议错误时由门店信息页禁止保存并提示修正。

## 已提交资料交互规则

- 营业执照、经营许可证和法人身份证可打开脱敏资料预览；预览关闭后回到本页，不改变已提交资料。
- 联系人仅展示脱敏后的联系信息，不提供本页修改入口。

## 页面元素细节

| 元素 | 类型 | 交互与规则 |
|---|---|---|
| 审核进度 | 状态 | 根据审核状态显示节点和提示；审核中仍可使用门店信息入口。 |
| 查看审核意见 | 跳转 | 仅在“需修改”状态展示，进入补充商户资料页。 |
| 已提交资料 | 资料预览 | 证件资料按脱敏规则展示。 |
| 门店信息 | 资料概览 | 展示七项维护字段及必填标识。 |
| 去维护 / 任一门店字段行 | 跳转 | 进入门店信息页维护当前绑定门店。 |

## V7 已确认规则

- 一个手机号对应一个商户账号和一个门店；当前账号只管理与其绑定的一个门店。
- 资质审核中可查看和编辑门店信息、回答游客问题、导入自己的知识材料和修改密码。
- 资质审核状态为“需修改”时仍可登录，仅限制重新提交资质资料，其他已开放功能继续可用。
- 必填字段为门店名称、详细地址、门头照、商户简介；特色菜介绍、商户电话、美团门店链接为非必填。
- 美团门店链接为空时用户端隐藏跳转按钮；非空时仅允许 `http://` 或 `https://` URL，链接失效、无法打开或无法识别时用户端提示“店铺建设中”。
