# 铜梁旅游商户端 - 商户资料

## 页面摘要

展示商户资质审核进度、已提交证件和当前门店资料，并支持直接维护门店字段。本页的门店信息区与门店信息页采用相同的字段结构和行内编辑交互；本页不再提供“账号与安全”或“修改密码”入口。

## 页面模块

- 审核进度：展示资料提交、平台审核和审核结果三个节点。
- 审核提示：审核中不影响正常使用；当资质需修改时展示审核意见入口。
- 已提交资料：展示营业执照、经营许可证、法人身份证和联系人信息；证件资料仅支持脱敏预览。
- 门店信息：展示当前账号绑定门店的七项维护字段，并在当前页面直接编辑和保存。

## 审核状态与权限

- 审核中时，商户可继续查看和编辑门店信息、回答游客问题、导入自己的知识材料和修改密码。
- 资质状态为“需修改”时，商户仍可登录；仅重新提交资质资料受限，其他已开放功能继续可用。
- 资质审核与 AI 内容合规审核独立执行，互不阻断。

## 【门店信息】字段说明

| 字段 | 本页展示 | 必填 | 维护方式 |
|---|---|---|---|
| 门店名称 | 当前名称 | 是 | 点击右侧铅笔展开文本输入框。 |
| 详细地址 | 当前地址 | 是 | 点击右侧铅笔展开文本输入框。 |
| 门头照 | 当前图片 | 是 | 点击右侧铅笔展开图片选择、删除和取消操作。 |
| 商户简介 | 当前简介 | 是 | 点击右侧铅笔展开多行输入框。 |
| 特色菜介绍 | 当前内容或“未填写” | 否 | 点击右侧铅笔展开多行输入框。 |
| 商户电话 | 当前号码或“未填写” | 否 | 点击右侧铅笔展开文本输入框。 |
| 美团门店链接 | 当前链接或“未填写” | 否 | 点击右侧铅笔展开链接输入框。 |

- 本区明确展示四项必填字段和三项非必填字段，避免商户在资料概览中混淆字段要求。

## 门店信息交互规则

- 当前手机号仅对应一个商户账号和一个门店，本页只展示该绑定门店的信息。
- 点击字段右侧铅笔按钮，在当前字段下方展开与门店信息页一致的编辑器。
- 点击“保存”后更新当前字段展示值、关闭编辑器并提示“已保存”；点击“取消”关闭编辑器，不保存本次输入。
- 门店名称、详细地址和商户简介为空时禁止保存并提示“请先填写内容”；门头照删除后提示重新上传。
- 特色菜介绍、商户电话和美团门店链接允许保存为空值；为空时展示“未填写”。
- 美团门店链接非空时仅允许标准 `http://` 或 `https://` URL；格式或协议错误时禁止保存并提示“请输入正确的 http/https 链接”。

## 已提交资料交互规则

- 营业执照、经营许可证和法人身份证可打开脱敏资料预览；预览关闭后回到本页，不改变已提交资料。
- 联系人仅展示脱敏后的联系信息，不提供本页修改入口。

- 本页门店信息区与 `store-info.html` 共用相同的字段维护结构和保存逻辑。

## V7 已确认规则

以下规则直接继承《V7商户端规则定义文档-20260831.md》，用于页面元素验收：

- 资质审核中可查看和编辑门店信息、回答游客问题、导入自己的知识材料和修改密码。
- 资质审核状态为“需修改”时仍可登录，仅限制重新提交资质资料，其他已开放功能继续可用。
- 资质审核与 AI 内容合规审核相对独立，互不影响。
- 一个手机号对应一个商户账号和一个门店；当前账号只管理与其绑定的一个门店。
- 运营后台停用账号、账号审核不通过时禁止登录。
- 连续 180 天未使用由系统自动限制账号并禁止登录；商户可联系平台申请恢复。
- 账号被停用或限制后，已登录设备在下一次请求时校验状态并使登录态失效。
- 账号被停用或限制后不要求设备立即主动退出；下一次请求失效后才清除当前登录态。
- 失效后禁止继续保存或提交，并提示：`账号已停用，请联系平台`。
- 退出登录清除当前设备登录态、本地草稿和未提交知识编辑内容；不影响服务端已提交、审核中或已生效内容。
- 必填字段为门店名称、详细地址、门头照、商户简介。
- 非必填字段为特色菜介绍、商户电话、美团门店链接；为空时显示“未填写”，不阻断其他字段保存。
- 商户手动录入自己的“美团门店链接”；允许标准 `http://` 或 `https://` URL，不限制域名必须是美团。
- 不要求必须是美团小程序链接；`javascript:`、`data:`、`ftp:` 等非 http/https 协议不允许保存。
- 空值允许保存；URL 格式错误或协议不是 http/https 时禁止保存并提示修正。
- 商户未填写链接时，用户端隐藏跳转按钮；普通 http/https 链接使用应用内网页打开，可识别深链时尝试跳转对应小程序。
- 链接失效、无法打开或无法识别时提示：`店铺建设中`。
